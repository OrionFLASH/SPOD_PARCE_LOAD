# Excel-каталог параметров PROM/SPOD

## Назначение

Плоский перечень **изменяемых итоговых параметров**:

1. **Колонки** CSV (включая JSON-колонки как целое).
2. **Конечные JSON-ключи** — только листья со значениями (в т.ч. пустыми: `""`, `[]`).

Промежуточные объекты/контейнеры (`getCondition`, `employeeRating`, элемент массива и т.п.) **не** включаются.

Артефакт: **`SPOD_PARAMS_CATALOG.xlsx`**.

## Модель (как в каталогах полей / BigQuery field path)

| Что | В каталоге? |
|-----|-------------|
| Колонка `REWARD_CODE` | да — вид `КОЛОНКА` |
| Колонка `REWARD_ADD_DATA` | да — вид `КОЛОНКА`, тип ячейки JSON |
| Ключ `hidden` | да — `JSON-КЛЮЧ`, колонка CSV = `REWARD_ADD_DATA`, путь `hidden` |
| Ключ `getCondition.employeeRating.minRatingGOSB` | да — путь полный, имя `minRatingGOSB` |
| Объект `getCondition` | нет |
| Массив объектов `rewards` | нет (есть `rewards[].rewardCode`, `rewards[].amount`) |
| Массив скаляров `feature` | да — один параметр типа «массив со строками» |
| `(элемент массива)` | нет |

## Сборка

```bash
python src/Tools/build_spod_params_excel.py \
  --input-dir IN/SPOD_UPLOAD \
  --out Docs/params_catalog/SPOD_PARAMS_CATALOG.xlsx
```

## Колонки листа PARAMETERS

| Колонка | Смысл |
|---------|--------|
| Вид параметра | `КОЛОНКА` / `JSON-КЛЮЧ` |
| Колонка CSV | имя колонки; для JSON-ключа — колонка, где лежит JSON |
| Тип ячейки | `JSON` / `-` |
| Полный путь ключа | `ключ1.ключ2.ключ` (с `[]` для полей в массиве объектов); `-` для колонок |
| Имя параметра | колонка или последний сегмент пути |
| … | зависимости, описание, id, дубли, 3 примера, консистентность, статистика |

Оформление: заголовок по центру; данные — вертикальный центр + перенос.

Доп. листы: `META`, `TABLES`.
