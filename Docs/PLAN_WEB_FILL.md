## Цель

1. Примеры JSON из PROM-SPOD совпадают с CSV: **нет строк и блоков, которых нет в выгрузке**.
2. Левая панель скрывается **только сама**; верхний и нижний колонтитулы остаются.
3. Справа — панель «Поиск и фильтры» (поиск, Турнир/Награда/Архив + новые фильтры), скрывается отдельно.
4. Цвета вкладок понятны без догадок (легенда внизу слева).
5. В edit и fill поля методов/кодов — списки с короткими подписями; `INDICATOR_CODE` — большой список **без своего варианта**.

## Диагностика (п. 1) — откуда берётся `t_CONTEST_00`

Пример: конкурс `CONTEST_00` («Приветственный»). В CSV `SCHEDULE` для него **нет строк**. В снимке `common/web-fill/examples/spod_fill_all_badges.json` уже лежит пустой объект `schedule[0]` с `TOURNAMENT_CODE: ""`.

Дальше цепочка:

| Шаг | Что происходит |
|-----|----------------|
| Экспорт | `src/Tools/export_web_fill_examples_from_spod.py` → `build_contest_data`: если в CSV нет расписания / индикаторов / групп / наград, **подставляется пустая строка-заглушка** (`if not sch_rows` / `if not ind_rows` / `if not badges` / пустая GROUP). |
| Импорт fill | `expandStoredPrefixedCode`: пустое окончание `TOURNAMENT_CODE` собирается в полный код **`t_<CONTEST_CODE>`** без хвоста. Для `CONTEST_00` это `t_CONTEST_00`. |
| UI fill | Если массив `schedule` пуст, код **сам добавляет** `emptyScheduleRow()` (суффикс `P1` + дефолты каталога, в т.ч. `TOURNAMENT_STATUS`). |

Пользователь видит в расписании турнир, которого не было в CSV. Серый тон «отменён» появляется, если у фантомной строки статус пустой / не из «живых» — либо после подстановки дефолта каталога.

**То же для INDICATOR:** пустой массив в CSV → одна пустая строка в JSON → в fill появляется блок индикатора, которого не было.

Правило на весь контур: **чего нет в CSV — в JSON не появляется**. Пустой массив `[]`, а не строка с пустыми полями.

## П. 1 — JSON строго по CSV

### Решение

1. Убрать заглушки в экспортере: нет строк SCHEDULE / INDICATOR / GROUP / REWARD-LINK → в снимке **`[]`**.
2. Не нормализовать «пустой» объект в фантомный турнир/индикатор.
3. Импорт fill: пустой `TOURNAMENT_CODE` / `REWARD_CODE` **не** разворачивать в `t_CODE` / `r_CODE`, если это единственная пустая заглушка; пустой массив расписания **не** дополнять `emptyScheduleRow()` при загрузке снимка.
4. `emptyScheduleRow()` / пустой индикатор — только по явной кнопке «Добавить».
5. Прогон сверки: все конкурсы из `IN/PROM/SPOD` × листы CONTEST, GROUP, INDICATOR, SCHEDULE, REWARD, REWARD-LINK. Число строк в JSON = число строк CSV с тем же `CONTEST_CODE`.
6. Пересобрать все `examples/*.json`.

### Не путать

Новый конкурс «с нуля» в UI по-прежнему может иметь стартовые слоты из каталога. Запрет — только на **импорт/экспорт существующих данных**.

## П. 2 — Скрытие левой панели

Сейчас `.app.is-sidebar-collapsed` прячет `.chrome-top` и `.chrome-foot`.

Нужно: `--side-w: 0`, левая колонка исчезает, **шаги сверху и подвал снизу остаются**. Кнопка «Конкурсы» по краю — без текста «и колонтитулы».

## П. 3 — Правая панель «Поиск и фильтры»

Сетка `chrome-mid`: `левая | workspace | правая`.

**Слева остаётся:** заголовок «Конкурсы», список вкладок, «Добавить / Копировать», легенда (п. 7).

**Справа переносится:** поиск; чипы «Турниры / Награды / Архив».

Скрытие правой панели **независимо** от левой (`is-filters-collapsed`, своя кнопка по правому краю). На узком экране панели складываются над/под workspace, не ломая колонтитулы.

## П. 4–6 — Новые фильтры (AND между группами)

Все фильтры на правой панели. Внутри группы — ИЛИ (выбранные значения), между группами — И.

### ПРОМ / ТЕСТ

Поля: `CONTEST_FEATURE.vid` и `CONTEST.TARGET_TYPE`.

| Выбор | Показ |
|-------|--------|
| Оба вкл. (или оба выкл. трактуем как «не режем по среде») | Все, с учётом прочих фильтров |
| Только ПРОМ | Хотя бы в одном из двух полей есть подстрока `ПРОМ` |
| Только ТЕСТ | Хотя бы в одном из двух полей есть подстрока `ТЕСТ` |

Регистр не важен. Пустые оба поля — не проходят узкий фильтр «только ПРОМ» / «только ТЕСТ».

### Статус расписания `TOURNAMENT_STATUS`

Чипы: АКТИВНЫЙ, ПОДВЕДЕНИЕ ИТОГОВ, ЗАВЕРШЕН, ОТМЕНЕН, УДАЛЕН.  
По умолчанию вкл.: **АКТИВНЫЙ, ПОДВЕДЕНИЕ ИТОГОВ, ЗАВЕРШЕН**.

Конкурс виден, если **есть хотя бы один** период с любым из включённых статусов.  
Нет строк расписания → не проходит статус-фильтр (отдельный тон «нет турниров» в легенде).

### Дата

Один date-picker (уже есть в fill). Конкурс виден, если у **хотя бы одного** периода дата попадает в `[START_DT, END_DT]` включительно. Пустой фильтр даты — не режет. Битые/пустые даты периода — период не матчится.

## П. 7 — Легенда цветов (предложение)

Текущий приоритет уже в `contestScheduleListTone` (менять логику не нужно, только подписать):

| Цвет вкладки | Смысл |
|--------------|--------|
| Зелёный | Есть **активный** |
| Синий | Нет активных, есть **подведение итогов** |
| Розовый | Нет живых, есть **завершённые** |
| Серый | Только **отменён / удалён** |
| Янтарный | Нет турниров / нет ключевых статусов |

**Не таблица-матрица.** Компактный столбик внизу левой панели:

```
Цвет списка
● Активный
● Подведение
● Завершён
● Отменён / удалён
● Нет турниров
```

Под заголовком одна строка: «по самому «живому» статусу в расписании». Подсказка `data-tip` с полной формулировкой приоритета.

## П. 8–15 — Каталог: списки и подписи

Источник: карточки в **web-edit** (и web-edit-full). Затем `sync_web_fill_catalog.py`.  
Чип fill: крупно подпись, мелко код. В CSV уходит код.

### 8. `INDICATOR_CODE` — `dropdown` (не `dropdown_custom`)

Сейчас: `dropdown_custom`, варианты только `WAIT`.  
Нужно: фиксированный список, **своего варианта нет**, дефолт `WAIT`.

Значений много → не лента чипов на всю карточку.

**UI:** поле-комбобокс: поиск по коду; список сгруппирован по префиксу (`PULMIS_`, `PFIMIS_`, `EFFICIENCYARS…`, `KANBANARS_…_VKS` / `_VKO`, …); в группе — сами коды. Подписи к кодам не обязательны (коды самодостаточны). Клавиатура: стрелки, Enter, Esc.

## Проверки приёмки

- `CONTEST_00` в JSON: `schedule: []`, `indicator: []` (если так в CSV); после импорта в fill нет `t_CONTEST_00`.
- Скрытие слева: шаги и «Импорт/Сохранить JSON» на месте.
- Правая панель скрывается, левая нет (и наоборот).
- ПРОМ/ТЕСТ / статус / дата — по правилам выше на снимке `spod_fill_all_badges.json`.
- Легенда совпадает с цветом вкладок.
- `INDICATOR_CODE`: нельзя ввести произвольный код; `WAIT` по умолчанию; список ищется.
- Fill и fill-full ведут себя одинаково.
