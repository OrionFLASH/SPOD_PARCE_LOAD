Справочник ФИО

Один общий справочник ФИО ↔ табельный для всех турниров режима FIO — загрузите JSON или таблицу с колонками ФИО и табельного один раз, он применится сразу ко всем таким турнирам при проверке и формировании.

ФИО не найдены в справочнике

Укажите табельные — они попадут в справочник. Или продолжите с 00000000.

Проблемы в таблице ФИО

Дубли и строки с пустым или нечисловым табельным. Отмечено, какая строка взята в справочник.

Загрузить турниры из исходных файлов

SCHEDULE — список турниров, статусы и период; CONTEST — название и план; REPORT — дата (необязателен, без него дата = сегодня).

Обновить REPORT

Строки отмеченных турниров в загруженном REPORT будут полностью заменены новыми (готовыми к выгрузке); всё остальное в файле не меняется. Новый файл скачается с меткой времени в имени.
