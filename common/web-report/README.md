# web-report — подготовка REPORT из турниров

Локальная страница в духе `web-edit-full` / `web-fill-full`: несколько турниров, загрузка CSV/Excel, справочник ФИО, разрешение дублей, выгрузка CSV и XLSX по логике Power Query (FIO + TN в одном контуре).

План: [`Docs/PLAN_WEB_REPORT.md`](../../Docs/PLAN_WEB_REPORT.md). Чеклист: [`Docs/TODO_WEB_REPORT.md`](../../Docs/TODO_WEB_REPORT.md).

## Открытие

Нужен HTTP (для `config.json`):

```bash
cd common/web-report && python3 -m http.server 8770
```

Порт по умолчанию — в `config.json` → `http_port`. Открыть `http://127.0.0.1:8770/report_app.html`.

## Как работать

1. **Пустая форма** или **Открыть JSON** настроек (`examples/settings_example.json`).
2. **+ Турнир** — заполнить CONTEST_CODE, TOURNAMENT_CODE, PLAN_VALUE, дату, FULL_NAME, тип `TN` или `FIO`.
3. Режим **FIO**: загрузить справочник (`examples/fio_dictionary_example.json`) или вести его в процессе; **Сохранить** — JSON для следующих прогонов.
4. **Загрузить CSV / Excel** — для CSV разделитель `;`; кодировка подбирается автоматически (UTF-8 / Windows-1251 / CP866). Указать колонку идентификатора и показателя.
5. **Сформировать**:
   - ненайденные ФИО → диалог (дописать табельные в справочник / продолжить с `00000000` / отмена);
   - дубли по `CONTEST_CODE|TOURNAMENT_CODE|MANAGER_PERSON_NUMBER` → остановить / убрать все из CSV / выбрать строку / сумма показателя.
6. Скачать **CSV** (только согласованные 7 колонок) и **XLSX** (все строки + колонки PQ + `КОММЕНТАРИЙ_ДУБЛЬ`).

Черновик настроек и справочника пишется в `localStorage` (ключи из `config.json`).

## Формат JSON настроек

```json
{
  "version": 1,
  "kind": "spod_web_report_settings",
  "tournaments": [
    {
      "id": "…",
      "contest_code": "01_2026-1_16-2_1",
      "tournament_code": "t_01_2026-1_16-2_1_2012",
      "plan_value": "100.00000",
      "contest_date": "2026-09-17",
      "full_name": "…",
      "type_ind": "TN",
      "column_id": "ТАБЕЛЬНЫЙ НОМЕР",
      "column_fact": "ПОКАЗАТЕЛЬ",
      "source_file_name": ""
    }
  ]
}
```

Данные строк в JSON настроек **не** хранятся — только параметры; файлы CSV/Excel загружаются отдельно.

## Формат справочника ФИО

```json
{
  "version": 1,
  "kind": "spod_web_report_fio_dictionary",
  "entries": [
    { "fio": "Иванов Иван Иванович", "person_number": "12345" }
  ]
}
```

Первоначальное заполнение: вручную в JSON или через диалог «ФИО не найдены» при формировании (введённые табельные дописываются и сохраняются кнопкой «Сохранить»).

## CSV (выход)

Колонки: `MANAGER_PERSON_NUMBER`, `CONTEST_CODE`, `TOURNAMENT_CODE`, `CONTEST_DATE`, `PLAN_VALUE`, `FACT_VALUE`, `priority_type`.  
Разделитель `;`, числа с точкой и 5 знаками, табельный слева дополнен нулями до 20 символов, `priority_type` = `1`.

## XLSX (выход)

Как в PQ: те же поля + `CONTEST-DATA=>FULL_NAME`, `ДУБЛЬ`, `СУММА ПО ТАБЕЛЬНОМУ`, `В ФОРМАТЕ`, числовые служебные, `FIO`, `ТАБЕЛЬНЫЙ НЕ НАЙДЕН`, плюс `КОММЕНТАРИЙ_ДУБЛЬ` (что выбрано по дублям). В книгу попадают **все** строки группы дублей; в CSV — только согласованные.

## Если что-то пошло не так

| Ситуация | Что делать |
|----------|------------|
| Кракозябры в CSV | Проверить разделитель `;`; страница сама пробует UTF-8 / 1251 / 866 — сохраните файл в UTF-8 при сомнениях |
| «Нет данных у турнира» | Сначала загрузить файл на карточке турнира |
| Все ФИО «не найдены» | Загрузить/дополнить справочник; регистр ФИО не важен |
| Дубли неожиданны | Один и тот же табельный в одном турнире/конкурсе — ожидаемо; выберите сумму или одну строку |
| Excel не читается | Нужен `.xlsx` (или `.xls`); рядом должен быть `xlsx.full.min.js` |
| `config.json` не грузится | Открывать через HTTP, не как `file://` |
| Сброс черновика | Очистить localStorage ключей из `config.json` или открыть другой JSON настроек |
