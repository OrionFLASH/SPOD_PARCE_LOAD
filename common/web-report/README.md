# web-report — подготовка REPORT из турниров

Локальная страница в духе `web-edit-full` / `web-fill-full`: три панели, этапы готовности, выгрузка CSV/XLSX.

Планы: [`Docs/PLAN_WEB_REPORT.md`](../../Docs/PLAN_WEB_REPORT.md), [`Docs/PLAN_WEB_REPORT_TODO3.md`](../../Docs/PLAN_WEB_REPORT_TODO3.md).  
Чеклист: [`Docs/TODO_WEB_REPORT.md`](../../Docs/TODO_WEB_REPORT.md).

## Открытие (только локально через HTTP)

```bash
cd common/web-report && python3 -m http.server 8770
```

Открыть `http://127.0.0.1:8770/report_app.html`. Порт — `config.json` → `http_port`.

Старт **без** автозагрузки прошлых сессий: турниры появляются после «Добавить» или загрузки JSON.

## Ключевые возможности (волна 26.16–26.17)

- Превью источника: все колонки, горизонтальный скролл, подсветка выбранных.
- Показатель: без изменений / × / ÷ / + / − (например ×100 для процентов Excel → 50 вместо 0.5).
- Справочник ФИО в центре при типе FIO; при TN скрывается.
- Копия турнира: блокировка снимается после смены **и кода, и названия**.
- Галочка «Включать в проверку и выгрузку» — выключенные не блокируют остальные.
- JSON v2: параметры + период + операции + вложенные файлы (base64) + настройки ФИО; при загрузке файлы восстанавливаются, отсутствующие колонки/листы подсвечиваются.
- Период: Y / Q1–Q4 / M1–M12 / F; метка в списке; колонки PERIOD / PERIOD_CODE в Excel.
- CSV: блок при дублях ключа, ТН ≠ 20 цифр, пустых ячейках; Excel доступен с колонкой CSV_ERROR.
- Диалог дублей: по умолчанию отмечена **первая** строка; нельзя оставить несколько строк одного ключа (иначе CSV снова блокировался). При повторной проверке показываются ранее принятые решения.
- Превью источника и ФИО: прокрутка по горизонтали и вертикали, закреплённый заголовок без наложения строк; показ не более `preview_row_limit` (по умолчанию 100) строк.
