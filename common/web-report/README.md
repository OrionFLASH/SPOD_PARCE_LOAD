# web-report — подготовка REPORT из турниров

Локальная страница в духе `web-edit-full` / `web-fill-full`: три панели (турниры / рабочая область / фильтры), скрываемые края, этапы готовности сверху, выгрузка CSV/XLSX.

План: [`Docs/PLAN_WEB_REPORT.md`](../../Docs/PLAN_WEB_REPORT.md). Чеклист: [`Docs/TODO_WEB_REPORT.md`](../../Docs/TODO_WEB_REPORT.md).

## Открытие

```bash
cd common/web-report && python3 -m http.server 8770
```

Открыть `http://127.0.0.1:8770/report_app.html`. Порт — `config.json` → `http_port`.

## Интерфейс

| Зона | Содержание |
|------|------------|
| **Верх** | Бренд, этапы готовности, Проверить / Сформировать / CSV / XLSX; кнопка свернуть этапы |
| **Слева** | Список турниров (подсветка активного), Добавить / Копировать / Удалить, JSON настроек, справочник ФИО |
| **Центр** | Карточка параметров (выровненная сетка, длинное название) + карточка источника (лист Excel, колонки, превью строк) |
| **Справа** | Поиск, фильтр TN/FIO, готовность (готовые / неполные / копии) |

Кнопки по краям «Турниры» / «Фильтры» — как в fill-full.

### Этапы (чипы сверху)

1. Турниры есть  
2. Поля заполнены (+ после копии сменены код и название)  
3. Источники и колонки выбраны  
4. ФИО/данные (для FIO — справочник или разрешение)  
5. Без дублей (или дубли разрешены)

### Копирование турнира

«Копировать» дублирует параметры и данные. Код турнира и наименование подсвечиваются оранжевым — **оба нужно изменить**, иначе формирование и проверка заблокированы.

### Проверка и формирование

- **Проверить** — отдельно: «всё ОК» или список проблем с кнопками дополнить ФИО / разрешить дубли.  
- **Сформировать** — те же диалоги при необходимости; без заполненных параметров кнопка неактивна / alert.

## Выгрузка

- **CSV** — 7 согласованных колонок, `;`, BOM.  
- **XLSX** — полный набор + комментарии дублей; **закреплена 1-я строка**, **автофильтр**, **автоширина** колонок.

## Если что-то не так

| Ситуация | Действие |
|----------|----------|
| Не формируется | Смотрите красные этапы: поля, источник, копия без смены кода/имени |
| Excel с несколькими листами | В карточке данных выберите лист — превью обновится |
| Кракозябры CSV | Разделитель `;`; кодировка подбирается (UTF-8 / 1251 / 866) |
| Дубли / ФИО | «Проверить» или диалоги при «Сформировать» |
| `config.json` не грузится | Только через HTTP, не `file://` |
