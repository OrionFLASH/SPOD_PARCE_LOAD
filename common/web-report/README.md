# web-report — подготовка REPORT из турниров

Локальная страница в духе `web-edit-full` / `web-fill-full`: три панели, этапы готовности, выгрузка CSV/XLSX.

Планы: [`Docs/PLAN_WEB_REPORT.md`](../../Docs/PLAN_WEB_REPORT.md), [`Docs/PLAN_WEB_REPORT_TODO3.md`](../../Docs/PLAN_WEB_REPORT_TODO3.md).  
Чеклист: [`Docs/TODO_WEB_REPORT.md`](../../Docs/TODO_WEB_REPORT.md).

## Открытие (только локально через HTTP)

```bash
cd common/web-report && python3 -m http.server 8770
```

Открыть `http://127.0.0.1:8770/report_app.html`. Порт — `config.json` → `http_port`.

Старт **без** автозагрузки прошлых сессий: турниры появляются после «Добавить» или загрузки JSON.  
Правая панель фильтров при старте **свёрнута**, левая (турниры) открыта.

После распаковки архива: переименовать `*.script` по `ПРАВИЛЬНЫЕ_ИМЕНА.txt`, затем поднять `http.server` в папке страницы.

## Ключевые возможности (волны 26.16–26.37)

- **Этапы** в шапке: иконка + заголовок + пояснение; зелёный / красный / серый (idle). ФИО idle при TN или если нет FIO-турниров; при отсутствии активных к выгрузке остальные этапы тоже idle. Рядом — инфо-сводка (турниры, строки, результат).
- **Левая панель:** турниры + JSON; внизу у края — результат + Проверить / Сформировать / CSV / XLSX.
- **Правая панель:** фильтры + компактная статистика в одну колонку (подсказки при наведении).
- Карточка турнира: после периода/типа/OK — мини-метрики «всего / ошибки / в CSV».
- **JSON настроек:** кроме имени файла — `source_file_path` / `fio.file_path`; при открытии JSON файлы подтягиваются по пути (или `examples/имя`), восстанавливаются лист и колонки; «Применить» активна, если таблица ФИО загружена и колонки заданы.
- Новая загрузка CSV/Excel: угол → 1,1; колонки очищаются и подсвечиваются.
- Сетка источника/ФИО: **одна строка** лист · стр · кол · колонки; превью сворачиваемое (по умолчанию свёрнуто).
- **Новый турнир:** план = `0`, дата данных = сегодня; пустые обязательные поля подсвечиваются.
- Применение таблицы ФИО: «Загрузить таблицу ФИО» → выбор колонок → «Применить»; дубли → первая с корректным ТН; «Подробнее». Пример: `examples/sample_fio_dictionary.csv`.
- **Формат (26.37):** ТН — 20 цифр с ведущими нулями; PLAN/FACT — `0.00000` с округлением, минус допустим; дата `ГГГГ-ММ-ДД`; `priority_type` = 1. Нечисловой показатель блокирует CSV с причиной (не превращается в 0). Подробно — `Docs/PLAN_WEB_REPORT.md`.
- Include-галочка; JSON v3 без base64; период Y/Q/M/F; CSV-гейты и диалог дублей.

## config.json (фрагмент)

| Ключ | Назначение |
|------|------------|
| `http_port` | Порт локального HTTP (подсказка) |
| `preview_row_limit` | Макс. строк в превью источника/ФИО (100) |
| `person_number_length` | Длина табельного в выгрузке (20) |
| `number_decimals` | Знаков после точки у PLAN/FACT (5) |
| `csv_delimiter` | Разделитель CSV (`;`) |
| `local_storage_*` | Ключи (черновик на старте не подгружается) |
