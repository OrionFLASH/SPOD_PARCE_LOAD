# Редактор описания параметров BADGE (web-edit)

HTML-страница в стиле **Apple Liquid Glass**.

## Данные

- **Источник правды — `catalog.json`** (или снимок `catalog_….json` через «Выбрать файл»).
- При старте страница **не** подгружает каталог сама: показывается экран «Откройте catalog.json».
- После выбора файла baseline сбрасывается — меток «отредактировано» сразу после импорта быть не должно.
- Черновик правок может лежать в `localStorage`; кнопка **«Продолжить черновик»** появляется только если черновик есть (не автозагрузка).
- **«Перечитать catalog.json»** — явно прочитать `./catalog.json` по HTTP (Live Server).
- Копия для blank: `../param_catalog_review/catalog.json`.
- Файл **`catalog.js` в web-edit не используется** редактором (зеркало для других утилит/review при необходимости).
- **«Сохранить JSON»** пишет каталог сюда (или куда укажете в диалоге). Учебные примеры JSON — в **`../examples/`**, не в папку редактора.

## Цикл

1. Откройте `game_edit_parameters.html` → «Выбрать catalog.json».
2. Правки → «Сохранить JSON» → положите файл обратно в `web-edit/game_edit_catalog.json` (и при необходимости в `param_catalog_review/`).
3. Токен `contest_badge_form_blank` читает `param_catalog_review/catalog.json`.

## Варианты и подписи (`variants` / `variant_labels`)

Для типов **Список**, **Список + свой**, **Массив** в карточке поля два блока в одном порядке строк:

| Блок | Поле JSON | Назначение |
|------|-----------|------------|
| Варианты (значения) | `variants` | Коды SPOD / CSV (`Y`, `N`, …) |
| Подписи (текст) | `variant_labels` | Понятный текст на кнопках (`Да`, `Нет`, …), **необязательно** |

- В CSV и Excel blank уходит **значение** из `variants`.
- В fill / дефолтах на чипе: крупно подпись (если есть), мелко код.
- Число строк может не совпасть: лишние подписи игнорируются; недостающие = на кнопке только код.
- Для `Y` / `N` в каталоге уже проставлено «Да» / «Нет».

Календарь даты: в попапе быстрые кнопки «Нач. мес.», «Кон. мес.», «Сегодня» (плюс чипы начала/конца года и «Бесконечный» у поля).

## Длинные списки (≥ 16 вариантов)

Для `dropdown` / `dropdown_custom` / `list` с большим числом кодов (типично `INDICATOR_CODE`) блок дефолта **не раздувает карточку чипами**:

- поднимается **сразу под шапку**, на всю ширину;
- список — **combobox с поиском** (группы по префиксу до `_`, отдельно VKS/VKO);
- для `list` остаются чипы, но с полем фильтра и прокруткой.

Короткий список по-прежнему чипами в обычном блоке «Значение по умолчанию».

## Пересборка каталога из схемы

```bash
python src/Tools/build_param_review_editor.py
```

## Связка с заполнением SPOD

После правок каталога синхронизируйте форму заполнения:

```bash
python src/Tools/sync_web_fill_catalog.py
```

Страница: `../web-fill/game_fill_settings.html` (скрипт обновляет `catalog.json` / `catalog.js` **в web-fill** и блок `EMBEDDED_CATALOG` в `game_fill_settings.html`).

Полный скан PROM → **`../web-edit-full/`** (`build_web_edit_full_catalog.py`). Fill с отдельными css/js: **`../web-fill-full/`**.
